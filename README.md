# SAQI DIGITAL HUB — GitHub Pages Website

## Publish
1. Create a GitHub repository.
2. Upload all files and folders from this ZIP into the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. For a custom domain, enter it in GitHub Pages settings and follow your domain provider's DNS setup.
6. Replace `YOUR-DOMAIN.com` in canonical URLs, `robots.txt`, and `sitemap.xml` with your actual domain.

## Menu
The top-right three-line button opens a side menu. It changes into an X close icon and includes Home, Services, Pricing, Shop Now, Payment Methods, Ads & Offers, Warranty & Policy, Contact and FAQ.

## Brand logos
The service page attempts to load available brand SVG icons automatically from the Simple Icons CDN. Some IPTV/local service brands are not in that library, so their names remain as text. This is not guaranteed to supply every official logo. The SAQI brand mark is a temporary CSS-made mark; replace it with your official logo asset when ready.
